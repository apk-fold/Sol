# Sol

Εφαρμογή Android της οικογένειας **apk-fold**, υπό προετοιμασία.

Δεν υπάρχει ακόμη τίποτα για λήψη: το APK και η περιγραφή των λειτουργιών θα έρθουν εδώ με την πρώτη έκδοση.

## Οι άλλες εφαρμογές apk-fold

- [Haiku](https://github.com/apk-fold/haiku): διαχειριστής κωδικών πρόσβασης εκτός σύνδεσης
- [Opus](https://github.com/apk-fold/opus): πρόγραμμα αναπαραγωγής μουσικής για Navidrome
- [Sonnet](https://github.com/apk-fold/sonnet): πρόγραμμα-πελάτης Jellyfin
- [Mythos](https://github.com/apk-fold/mythos): σουίτα γραφείου με συγχρονισμό χωρίς διακομιστή
- [Fable](https://github.com/apk-fold/fable): καταγραφή ωρών εργασίας
