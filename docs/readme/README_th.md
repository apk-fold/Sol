# Sol

แอป Android ในตระกูล **apk-fold** ซึ่งกำลังอยู่ระหว่างการเตรียม

ตอนนี้ยังไม่มีอะไรให้ดาวน์โหลด: ไฟล์ APK และรายละเอียดฟีเจอร์จะมาอยู่ที่นี่พร้อมกับเวอร์ชันแรก

## แอป apk-fold อื่น ๆ

- [Haiku](https://github.com/apk-fold/haiku): ตัวจัดการรหัสผ่านแบบออฟไลน์
- [Opus](https://github.com/apk-fold/opus): เครื่องเล่นเพลงสำหรับ Navidrome
- [Sonnet](https://github.com/apk-fold/sonnet): ไคลเอนต์ Jellyfin
- [Mythos](https://github.com/apk-fold/mythos): ชุดโปรแกรมสำนักงานที่ซิงค์ได้โดยไม่ต้องมีเซิร์ฟเวอร์
- [Fable](https://github.com/apk-fold/fable): บันทึกชั่วโมงทำงาน
