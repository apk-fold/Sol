# Sol

**apk-fold** family ki ek Android app, abhi tayyari mein hai.

Filhal download karne ke liye kuch nahin: APK aur features ki tafseel pehle version ke saath yahan aa jayegi.

## apk-fold ki doosri apps

- [Haiku](https://github.com/apk-fold/haiku): offline password manager
- [Opus](https://github.com/apk-fold/opus): Navidrome ke liye music player
- [Sonnet](https://github.com/apk-fold/sonnet): Jellyfin client
- [Mythos](https://github.com/apk-fold/mythos): server ke baghair sync hone wala office suite
- [Fable](https://github.com/apk-fold/fable): kaam ke ghanton ka hisaab
