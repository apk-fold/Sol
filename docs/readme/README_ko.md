# Sol

**apk-fold** 패밀리의 Android 앱으로, 현재 준비 중입니다.

아직 다운로드할 수 있는 것은 없습니다. APK와 기능 설명은 첫 번째 버전과 함께 이곳에 올라옵니다.

## 다른 apk-fold 앱

- [Haiku](https://github.com/apk-fold/haiku): 오프라인 비밀번호 관리자
- [Opus](https://github.com/apk-fold/opus): Navidrome용 음악 플레이어
- [Sonnet](https://github.com/apk-fold/sonnet): Jellyfin 클라이언트
- [Mythos](https://github.com/apk-fold/mythos): 서버 없이 동기화되는 오피스 제품군
- [Fable](https://github.com/apk-fold/fable): 근무 시간 기록
