# Sol

**apk-fold** കുടുംബത്തിലെ ഒരു Android ആപ്പ്, ഇപ്പോൾ തയ്യാറെടുപ്പിലാണ്.

ഇപ്പോൾ ഡൗൺലോഡ് ചെയ്യാൻ ഒന്നുമില്ല: APK-യും ഫീച്ചറുകളുടെ വിവരണവും ആദ്യ പതിപ്പിനൊപ്പം ഇവിടെ എത്തും.

## മറ്റ് apk-fold ആപ്പുകൾ

- [Haiku](https://github.com/apk-fold/haiku): ഓഫ്‌ലൈൻ പാസ്‌വേഡ് മാനേജർ
- [Opus](https://github.com/apk-fold/opus): Navidrome-നുള്ള മ്യൂസിക് പ്ലേയർ
- [Sonnet](https://github.com/apk-fold/sonnet): Jellyfin ക്ലയന്റ്
- [Mythos](https://github.com/apk-fold/mythos): സെർവർ ഇല്ലാതെ സിങ്ക് ചെയ്യുന്ന ഓഫീസ് സ്യൂട്ട്
- [Fable](https://github.com/apk-fold/fable): ജോലി സമയം രേഖപ്പെടുത്താനുള്ള ആപ്പ്
