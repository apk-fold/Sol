# Sol

اپلیکیشن اندرویدی از خانوادهٔ **apk-fold**، در حال آماده‌سازی.

فعلاً چیزی برای دانلود وجود ندارد: فایل APK و توضیح قابلیت‌ها همراه با نسخهٔ اول در اینجا قرار می‌گیرند.

## دیگر اپلیکیشن‌های apk-fold

- [Haiku](https://github.com/apk-fold/haiku): مدیر رمز عبور آفلاین
- [Opus](https://github.com/apk-fold/opus): پخش‌کنندهٔ موسیقی برای Navidrome
- [Sonnet](https://github.com/apk-fold/sonnet): کلاینت Jellyfin
- [Mythos](https://github.com/apk-fold/mythos): مجموعهٔ اداری با همگام‌سازی بدون سرور
- [Fable](https://github.com/apk-fold/fable): ثبت ساعات کاری
