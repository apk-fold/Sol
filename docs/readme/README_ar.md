# Sol

تطبيق Android من عائلة **apk-fold**، قيد التحضير.

لا يوجد ما يمكن تنزيله حاليًا: سيصل ملف APK ووصف الميزات إلى هنا مع الإصدار الأول.

## تطبيقات apk-fold الأخرى

- [Haiku](https://github.com/apk-fold/haiku): مدير كلمات مرور يعمل دون اتصال
- [Opus](https://github.com/apk-fold/opus): مشغّل موسيقى لـ Navidrome
- [Sonnet](https://github.com/apk-fold/sonnet): عميل Jellyfin
- [Mythos](https://github.com/apk-fold/mythos): حزمة مكتبية تتزامن دون خادم
- [Fable](https://github.com/apk-fold/fable): تتبّع ساعات العمل
