# Sol

Aplikasi Android dari keluarga **apk-fold**, sedang disiapkan.

Belum ada yang bisa diunduh: APK dan deskripsi fiturnya akan hadir di sini bersama versi pertama.

## Aplikasi apk-fold lainnya

- [Haiku](https://github.com/apk-fold/haiku): pengelola kata sandi offline
- [Opus](https://github.com/apk-fold/opus): pemutar musik untuk Navidrome
- [Sonnet](https://github.com/apk-fold/sonnet): klien Jellyfin
- [Mythos](https://github.com/apk-fold/mythos): paket perkantoran yang tersinkron tanpa server
- [Fable](https://github.com/apk-fold/fable): pencatat jam kerja
