# Sol

Android-застосунок із родини **apk-fold**, у розробці.

Поки що завантажувати нічого: APK та опис функцій з'являться тут разом із першою версією.

## Інші застосунки apk-fold

- [Haiku](https://github.com/apk-fold/haiku): офлайн-менеджер паролів
- [Opus](https://github.com/apk-fold/opus): музичний плеєр для Navidrome
- [Sonnet](https://github.com/apk-fold/sonnet): клієнт Jellyfin
- [Mythos](https://github.com/apk-fold/mythos): офісний пакет із синхронізацією без сервера
- [Fable](https://github.com/apk-fold/fable): облік робочого часу
