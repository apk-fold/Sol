# Sol

Android-приложение из семейства **apk-fold**, в разработке.

Скачивать пока нечего: APK и описание функций появятся здесь вместе с первой версией.

## Другие приложения apk-fold

- [Haiku](https://github.com/apk-fold/haiku): офлайн-менеджер паролей
- [Opus](https://github.com/apk-fold/opus): музыкальный плеер для Navidrome
- [Sonnet](https://github.com/apk-fold/sonnet): клиент Jellyfin
- [Mythos](https://github.com/apk-fold/mythos): офисный пакет с синхронизацией без сервера
- [Fable](https://github.com/apk-fold/fable): учёт рабочего времени
