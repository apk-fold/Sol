# Signaler une vulnérabilité

Ne publiez pas d'exemple de livre privé, d'archive potentiellement malveillante ou de données personnelles dans une issue publique.

Signalez les problèmes de sécurité au mainteneur du dépôt par un canal privé GitHub si celui-ci est activé. Incluez la version FoldBook, la version Android, l'extension et les étapes de reproduction. Pour les fichiers de test, utilisez de petits exemples fabriqués spécialement pour le rapport.

Les zones à examiner en priorité sont l'extraction des archives, les analyseurs XML, le rendu WebView des fichiers importés et les autorisations URI Android.
