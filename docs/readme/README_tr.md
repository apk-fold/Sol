# Sol

**apk-fold** ailesinden bir Android uygulaması, hazırlık aşamasında.

Şimdilik indirilecek bir şey yok: APK ve özelliklerin açıklaması ilk sürümle birlikte burada olacak.

## Diğer apk-fold uygulamaları

- [Haiku](https://github.com/apk-fold/haiku): çevrimdışı parola yöneticisi
- [Opus](https://github.com/apk-fold/opus): Navidrome için müzik çalar
- [Sonnet](https://github.com/apk-fold/sonnet): Jellyfin istemcisi
- [Mythos](https://github.com/apk-fold/mythos): sunucu olmadan senkronize olan ofis paketi
- [Fable](https://github.com/apk-fold/fable): çalışma saati takibi
