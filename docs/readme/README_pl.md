# Sol

Aplikacja na Androida z rodziny **apk-fold**, w przygotowaniu.

Na razie nie ma nic do pobrania: plik APK i opis funkcji pojawią się tutaj razem z pierwszą wersją.

## Pozostałe aplikacje apk-fold

- [Haiku](https://github.com/apk-fold/haiku): menedżer haseł offline
- [Opus](https://github.com/apk-fold/opus): odtwarzacz muzyki dla Navidrome
- [Sonnet](https://github.com/apk-fold/sonnet): klient Jellyfin
- [Mythos](https://github.com/apk-fold/mythos): pakiet biurowy synchronizowany bez serwera
- [Fable](https://github.com/apk-fold/fable): ewidencja godzin pracy
