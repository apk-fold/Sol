# Sol

Ứng dụng Android thuộc gia đình **apk-fold**, đang được chuẩn bị.

Hiện chưa có gì để tải về: APK và phần mô tả tính năng sẽ xuất hiện ở đây cùng phiên bản đầu tiên.

## Các ứng dụng apk-fold khác

- [Haiku](https://github.com/apk-fold/haiku): trình quản lý mật khẩu ngoại tuyến
- [Opus](https://github.com/apk-fold/opus): trình phát nhạc cho Navidrome
- [Sonnet](https://github.com/apk-fold/sonnet): ứng dụng khách Jellyfin
- [Mythos](https://github.com/apk-fold/mythos): bộ ứng dụng văn phòng đồng bộ không cần máy chủ
- [Fable](https://github.com/apk-fold/fable): theo dõi giờ làm việc
